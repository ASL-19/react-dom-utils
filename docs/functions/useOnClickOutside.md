# Function: useOnClickOutside()

> **useOnClickOutside**(`options`): `void`

Detect clicks outside of specific component
This code is a slightly modified version of this: https://usehooks.com/useOnClickOutside/

## Parameters

### options

Hook options

#### handler

`CallableFunction`

Function called with `{ event }` on mousedown outside
the element

#### isEnabled

`boolean`

Whether to call `handler`

#### ref

`RefObject`\<`HTMLElement` \| `null`\>

Ref attached to the element

## Returns

`void`
